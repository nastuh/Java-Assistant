# JavaAssistant — без AI, миллион логических Q&A и бесплатный Mini App

## Что сделано

- AI полностью убран.
- Ответы идут из локальной базы знаний.
- Есть обычные разговорные вопросы: «привет», «как дела», «спасибо», «пока».
- Есть вопросы о самом боте: что это, для чего создан, почему без AI, что находится в Mini App, как устроены XP, достижения, профиль и настройки.
- Есть большая база Java: JVM, JDK, JRE, переменные, типы, String, массивы, условия, циклы, методы, ООП, классы, объекты, конструкторы, this, static, final, инкапсуляция, наследование, полиморфизм, абстракция, интерфейсы, коллекции, ArrayList, LinkedList, HashMap, HashSet, equals/hashCode, исключения, try/catch, throw/throws, null, Stream API, lambda, Optional, generics, многопоточность, ExecutorService, synchronized, Git, Maven, Gradle, debug и т.д.

## Миллион вопросов

В `knowledge_base.py` есть детерминированный генератор `generated_question()` / `generated_answer()` и функция `million_count()`.

Он даёт **1 000 000 логических Q&A-комбинаций** из формулировок, тем и контекстов, не занимая сотни мегабайт одинаковым текстом.

Если нужен физический файл, его можно создать:

```bash
python generate_million.py
```

В базовой версии файл не создаётся автоматически, чтобы бот не загружал миллион строк в память при каждом старте.

## Бесплатный запуск Mini App без покупки домена

Telegram Mini Apps в обычной среде используют HTTPS. Для разработки здесь используется **Cloudflare Quick Tunnel**.

Он публикует локальный сервер через временный адрес вида:

```text
https://random-name.trycloudflare.com
```

Покупать домен не надо.

### Windows

1. Установи Python 3.11+.
2. Установи `cloudflared`.
3. Создай `.env` из `.env.example`.
4. Вставь токен BotFather:

```env
BOT_TOKEN=123456:ABC...
```

5. Установи зависимости:

```powershell
pip install -r requirements.txt
```

6. Запусти:

```text
run_free_auto.bat
```

Скрипт автоматически:

1. запускает Mini App на `127.0.0.1:8080`;
2. запускает Cloudflare Quick Tunnel;
3. получает HTTPS URL;
4. подставляет URL в переменную `WEBAPP_URL`;
5. запускает Telegram-бота;
6. кнопка «Открыть JavaAssistant» в `/start` использует этот URL.

**BotFather для Main Mini App при таком временном URL не нужен.** Используй кнопку из сообщения `/start`.

### macOS / Linux

```bash
pip3 install -r requirements.txt
python3 run_free_auto.py
```

или:

```bash
./run_free.sh
```

## Важное ограничение бесплатного способа

Quick Tunnel — временный адрес для разработки/демонстрации. При новом запуске адрес может измениться. Поэтому не используй его как постоянный production-адрес.

Для постоянного проекта позже можно перенести Mini App на бесплатный/условно-бесплатный хостинг с постоянным HTTPS.

## Mini App

- Главная — прогресс, XP, следующий урок.
- Обучение — 8 последовательных тем.
- Тесты — варианты ответа + объяснение.
- Достижения — награды за учебные действия.
- Профиль — уровень, XP, статистика.
- Настройки — язык и уведомления.

## Контакты

В `main.py` в обработчике `/contacts` замени текст на свои реальные Telegram/GitHub/email.
